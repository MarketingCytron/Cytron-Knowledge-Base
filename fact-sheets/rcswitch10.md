# Product fact sheets

## Product name
RCSwitch10 - RC controlled Relay Switch (RCS10A)

## Aliases
RCS10A, RCSwitch10, RCSwitch10 - RC controlled Relay Switch, RC Controlled Relay Switch, Cytron RCSwitch10, Cytron RC Relay Switch

## What it is
An RC controlled relay switch that can be turned on and off by using an RC controller. It has one single pole, double throw relay.

## Specs and functions
- Relay type: Single pole, double throw (product page)
- Max voltage: 250VAC, 30VDC (product page)
- Max current: 10A (product page)
- Dimension: 43.4mm x 38.3mm x 17.4mm (product page)
- Control: turned on and off by using an RC controller (product page)
- Warranty: 12 months (product page)
- Switching: ON (COM–NO) when the RC signal is below 1.2 ms, OFF (COM–NC) when it is above 1.8 ms; undetermined between 1.2 and 1.8 ms (connection diagram)
- No RC signal: switch is OFF (connection diagram)
- LEDs: Power LED (powered up), Switch LED (switch ON) (connection diagram)
- Supply: 4V–6V from the RC receiver into the RC IN +5V/GND terminals (connection diagram); current draw [NOT STATED]
- Relay: SONGLE SRD-05VDC-SL-C (photo in the connection diagram)
- Package contents: [NOT STATED]

## Interfaces and compatibility
- Input: RC IN 3-way screw terminal — signal, +5V, GND — wired to one receiver channel; use a 2-position switch channel, not a gimbal stick channel (connection diagram)
- Output: OUT 3-way screw terminal — NO, COM, NC; one SPDT relay contact set rated 250VAC, 30VDC, 10A (product page, connection diagram)
- Compatible RC receivers/transmitters: [NOT STATED]
- Software: none required; operated by an RC controller (product page)
- Fritzing part linked from the product page

## Use cases
- Powerful auxiliary weapons in RC combat tournament
- Glow plugs on nitro RC vehicles
- High powered lighting system on RC aircraft, boats and cars
- Domestic appliances and home automation
- Non-critical automotive electrics like glow wire

## Known limitations
- No Cytron datasheet; the Cytron connection diagram is the only document, and its product-page link returns "not found"
- Switch state is undetermined between 1.2 and 1.8 ms, so it must not be used on a gimbal stick channel
- Switch is OFF when no RC signal is received; a receiver that keeps sending pulses after losing the transmitter is not "no signal"
- Board current draw and package contents are not stated
- Contact rating is given only as 250VAC, 30VDC, 10A; no load-type derating is stated

## Positioning (kept apart from specs)
